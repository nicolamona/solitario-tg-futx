# Solitario TG FUTX

Solitario Klondike clásico en español, pensado para pantallas móviles y Telegram Mini Apps. Interfaz premium en tonos oscuros, verde paño y dorado.

## Incluye
- Tablero Klondike con siete columnas, mazo, descarte y cuatro bases.
- Robar y reciclar el mazo.
- Mover cartas con toque/clic y arrastrar en escritorio.
- Deshacer movimientos y sugerencias.
- Cronómetro, puntuación, contador de movimientos y récord local.
- Diseño adaptable a móvil y soporte básico de Telegram Web Apps.

## Publicar con GitHub Pages
1. Abre **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/ (root)`, y guarda.
4. Espera a que GitHub publique el sitio. La dirección suele ser `https://nicolamona.github.io/solitario-tg-futx/`.

Para abrirlo como Mini App, utiliza la URL HTTPS publicada en el botón de tu Mini App o en la configuración de tu bot de Telegram.

## Nota
El juego base no necesita servidor. El récord se guarda localmente en el navegador del jugador; no es una clasificación global.
